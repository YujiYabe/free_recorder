# Free Recorder

Free Recorderは、会議や打ち合わせの音声を端末内に保存するシンプルなAndroid録音アプリです。

文字起こし、ユーザー登録、クラウドへのアップロードは行いません。録音データを手元に残し、必要に応じて任意の文字起こしサービスなどへ渡したい場合に利用できます。

## 主な機能

- マイク音声をm4a（AAC、64kbps、44.1kHz）で録音
- 録音中もフォアグラウンドサービスで処理を継続
- アプリまたは通知から録音を停止
- 長時間の録音を自動的に複数ファイルへ分割
- 直近50件のファイル名、録音日時、ファイルサイズをアプリ内に表示
- 録音ファイルの保存先をアプリから開く
- 録音データはクラウドへ送信せず、端末内だけに保存

## 対応環境

- Android 8.0（API 26）以上
- 録音に必要な空き容量がある端末

## 使い方

1. アプリを起動します。
2. 「録音を開始」をタップし、初回のみマイク権限を許可します。
3. 録音中は、アプリを閉じても通知が表示されている間は録音が続きます。
4. アプリの「録音を停止」、または通知の「停止」をタップして保存します。
5. 「音声ファイルの場所を開く」から保存したファイルを確認します。

Android 13以降では、録音状態を通知に表示するため通知権限も求められます。

> [!IMPORTANT]
> 録音を始める前に、会議の参加者から同意を得て、利用地域や組織のルールを確認してください。

## 録音ファイル

ファイル名は、録音開始日時を使った `meeting_yyyyMMdd_HHmmss.m4a` 形式です。

長時間の録音では、1ファイルが大きくなりすぎないように分割されます。録音開始から25分を過ぎた後に無音を検知した時点で次のファイルへ切り替わり、無音がない場合も35分で切り替わります。分割中も録音は継続します。

保存先はAndroidのバージョンによって異なります。

| Android | 保存先 |
| --- | --- |
| Android 10以降 | `Music/Meeting Recorder/` |
| Android 8～9 | `Android/data/dev.yuji.freerecorder/files/Music/Meeting Recorder/` |

64kbpsで録音するため、ファイルサイズの目安は1時間あたり約29MBです。端末や録音内容によって実際のサイズは異なります。

## インストールと開発

このリポジトリにはビルド済みAPKを含めていないため、利用するにはソースコードからビルドしてください。

### 必要なもの

- Android Studio
- JDK 17
- Android SDK 35

Android Studioでこのリポジトリを開き、Gradle Syncの完了後、接続したAndroid端末またはエミュレーターで `app` を実行します。

コマンドラインからビルドする場合は、ローカルにGradleを用意して次を実行してください。

```bash
gradle :app:assembleDebug
```

生成されたAPKは `app/build/outputs/apk/debug/app-debug.apk` に配置されます。

> [!NOTE]
> `gradlew` スクリプトとWrapper設定はありますが、`gradle-wrapper.jar` はリポジトリに含まれていません。そのため、現状の `./gradlew` だけではビルドできません。

## プライバシーと権限

このアプリは録音データを外部サーバーへ送信しません。使用する権限は次のとおりです。

- マイク：音声を録音するため
- 通知：録音状態の表示と、通知から録音を停止するため
- フォアグラウンドサービス：アプリが画面に表示されていない間も録音を続けるため
